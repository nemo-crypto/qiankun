## 边界

保留 Vue 2 主/子应用演示结构；Vue 2 已结束社区常规维护。本项目作为迁移与微前端教学样例，不将其包装为新生产项目的默认框架选型。

移动端采用 Chromium 设备模拟，不是真机验收；Nginx 配置是部署参考，未在生产 Nginx 或外网部署验证。没有后端持久化、身份认证或多标签状态同步。
